### 核心 Model 字段

1. **`KnowledgeItem`**：

  - `CardType cardType`（枚举：`mapping` 配对 / `trueFalse` 是非判断 / `pair` 易混对比）
    
  - `String prompt`（题干/帽子/原话/对比项A）
    
  - `String answer`（核心结论/对比项B；对于 `trueFalse` 存放解析或正解）

  - 计算属性：`int get totalScore => singleCorrect * 1 + multiCorrect * 2;`。
    

## 四、确定性 Markdown 解析与无损增量合并协议

App 必须内置 `MdParserService`，按以下极简确定性语法解析 `assets/default_sheet.md` 与用户后续通过 `file_picker` 导入的 `.md` 文件：

Markdown

```
# 马原
## 1.1 基础概念与帽子
- [配对] 理解政治经济学的枢纽 == 劳动二重性理论 | 口诀: 劳二枢纽 #二轮
- [错] 意识和观念具有直接现实性 | 解析: 直接现实性为实践特有 | 墓碑词: 直接现实性
- [对] 人体解剖是猴体解剖的一把钥匙 | 解析: 看似生涩但正确的原话
- [对比] 工作重心转向城市（七届二中全会） <> 革命重心转向城市（1949年进北平） | 口诀: 工作七二，革命进京 #二轮
```

### 解析与合并铁律

1. `# <科目>` 切换当前 `subject`（模糊匹配包含“马原/史纲/思修/新思想/时政”）；`## <章节>` 切换 `chapter`；空行、非 `-` 开头行自动忽略。
  
2. 标签与分隔符：
  
  
  - 尾部含 `#二轮` 则 `isRound2Focus = true`（解析后从正文中剔除该标签）。
    
  - 使用 `|` 分割扩展字段，支持 `口诀:`、`解析:`、`墓碑词:`（逗号/顿号分隔）、`备注:`，均为可选字段，缺失不报错。
    
  - `[配对]` 用 `==` 拆分为 `prompt` 与 `answer`；`[对比]` 用 `<>` 拆分为 `prompt`（概念A）与 `answer`（概念B）；`[对]`/`[错]` 对应 `cardType = trueFalse` 及 `isTrue = true/false`。
    
3. **无损增量合并（关键需求）**：
  
  
  - 导入新 `.md` 时，通过稳定 `id` 匹配现有数据。
    
  - 命中已有 `id` 时：**严格保留**用户的 `status`（标星/模糊/眼熟）、`reviewCount`、`userNote`；若 `isCustomEdited == true`，默认保留用户改过的 `mnemonic`/`answer`（除非用户在导入弹窗中勾选“覆盖手动编辑内容”）。
    
  - 导入完成后弹出清晰汇总提示：`导入完成：新增 X 条，更新 Y 条，保留个人学习状态 Z 条`。
    

## 五、四大 Tab 功能详细需求

### Tab 1：一页纸（刷眼主场）

- **顶部吸顶控制区**：
  
  
  - 科目横向过滤条：全部 / 马原 / 史纲 / 思修 / 新思想 / 时政。
    
  - 状态过滤芯片：全量 / 仅标星 / 仅模糊 / 二轮冲刺（筛选 `isRound2Focus == true` 或 史纲+新思想+时政帽子）。
    
  - 关键词即时搜索框（折叠图标触发）+ 全局 **“遮罩模式”开关**。
    
- **条目卡片（极简高密度）**：
  
  
  - 根据 `cardType` 差异化排版：`mapping` 展示 `题干 → 结论`；`pair` 上下双行并排对比；`trueFalse` 左侧显示红/绿 `错/对` 徽章。
    
  - 开启遮罩模式后，所有结论/对比项右侧/对错徽章变为琥珀色遮罩块；**轻点遮罩块即可单独揭晓/重新遮盖**。
    
  - 若有 `mnemonic`，默认折叠为一个蓝色小胶囊“口诀”，点击原地展开，不喧宾夺主。
    
  - 底部提供轻量一行操作栏：眼熟（勾）/ 模糊（波浪）/ 标星（星），点击带轻微震动反馈。
    
- **长按原地热修**：长按任意条目弹出 BottomSheet，允许直接修改题干、结论、口诀、个人备注、是否二轮重点，保存后立即写入本地 JSON 并标记 `isCustomEdited = true`。
  
- **离线磨耳朵（Android TTS）**：右下角悬浮按钮弹出底部迷你播控条，按当前过滤列表顺序朗读：`朗读 prompt -> 停顿 1.5 秒 -> 朗读 answer`，支持播放/暂停、上一条/下一条、语速切换（1.0x / 1.25x / 1.5x）、单列表循环。
  

### Tab 2：反射场（4 种精准微训练）

首页为 4 张大卡片入口，每张卡片显示可用题量及一键开始（默认每局 15 题，抽题算法优先抽取 `fuzzy` 和 `starred`，再补 `unseen`，最后补 `familiar`）：

1. **是非滑卡（针对 `trueFalse`）**：
  
  
  - 单手大卡片堆叠：左滑判错（红色反馈）、右滑判对（绿色反馈），底部同时提供大号“错 / 对”按钮。
    
  - 判对直接切下一张；**判错时卡片原地展开解析**，用警示红高亮其中的 `tombstoneWords`，并自动将该条目设为 `fuzzy`（并推入本局队尾再考一次）。
    
2. **帽子配对（针对 `mapping`）**：
  
  
  - 单屏左栏 4 个 `prompt`、右栏 4 个打乱的 `answer`。
    
  - **点击配对（不要做拖拽连线）**：点选左侧一项再点选右侧一项；匹配成功则变绿并淡出消除，配错触发 `HapticFeedback.mediumImpact()` 并短时标红。4 组全消自动切下一批。
    
3. **双胞胎辨析（针对 `pair`）**：
  
  
  - 每次取 1 条 `pair` 数据（包含概念 A 与概念 B），将其拆分出“名称”与“核心特征”（如按括号或冒号拆分），在上方随机提问其中一个特征，下方给出 A/B 两个大按钮让用户秒选；点选后同屏高亮展示两者的完整对比差异与口诀。
    
4. **政经计算器（纯算法随机出题，不依赖 MD）**：
  
  
  - 两种题型可切换或混合：
    
    
    - **题型 A（$C/V/M$ 利润计算）**：随机生成总投资 $C+V$（如 100/120/200 万）、有机构成 $C:V$（如 3:1、4:1、7:3）、剩余价值率 $M:V$（如 100%、150%、200%），要求输入利润 $M$。提供“一步步提示”折叠区（先求 $V$，再由 $M/V$ 求 $M$）。
      
    - **题型 B（绝对/相对剩余价值率）**：随机生成原工作日总时长（如 8h/10h，必要/剩余平分或给定比例），随机出题“绝对方式延长剩余时间 X 小时”或“相对方式总时长不变、剩余变为 Y 小时”，求新的剩余价值率（%），并给出算式解析。
