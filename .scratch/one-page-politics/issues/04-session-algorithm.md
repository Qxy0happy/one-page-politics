# 04 — 复习会话算法与三态调度

Type: grilling
Status: resolved
Blocked by: —

## Question

把“高频刺激 + 条件反射”落成可执行的会话规则，不引入 SM-2/FSRS。需要定下：

- 进入一页纸刷眼时如何选卡：全量、按分类、按标签、随机，还是“今日队列”。
- 三态（会/模糊/不会）的语义与交互；是否允许跳过、撤销。
- “模糊/不会”如何回炉：立即重排、本轮队尾、下一轮，还是只记录不重排；回炉上限与退出条件。
- “遍数”如何定义与计数；一轮结束的标志；跨天是否继承未完成队列。
- 每日 15–30 分钟如何量化：按张数、按时间、按分类完成度；是否显示倒计时/进度条。
- 进度持久化：每张卡只存三态与时间戳，还是存会话历史；如何恢复中断的会话。
- 如何避免把工具做成“新的复习债务”：不强制定量、不惩罚中断、不制造红色逾期。

## Acceptance

回答中给出状态机、伪代码与至少三个具体场景（10 分钟碎片时间、30 分钟完整会话、隔三天未打开）。关键取舍由用户拍板。
