# 03 — MD 协议、卡片类型与内容指纹

Type: grilling
Status: resolved
Blocked by: —

## Question

设计 `assets/default_sheet.md` 的单一事实源格式，以及与之配套的解析/合并规则。需要定下：

- 分类层级（马原/史纲/思修/新思想/时政，以及子类）如何表达。
- 卡片类型：对应关系（考点＝结论）、判断正误（易错原话/墓碑词）、口诀、配对（帽子 4×4）、对比（双胞胎）、计算题参数。是否还需要“大题框架/角度”类型。
- 每条卡片的字段：正文、答案/结论、解析、标签、来源、类型专属字段；哪些字段可省略。
- 一条多义项（如“实践三特征”）拆成多张卡还是保留为一组；拆分的边界。
- 内容指纹：规范化规则（空白、标点、全半角、大小写、序号）如何定，保证同一内容稳定同 id、改字即新 id。
- 增量合并：新增、修改、删除条目时，旧进度如何处理；是否需要 tombstone；导入失败如何回滚。
- 首次 seed 的范围：只取整理文档“一页纸内容”，还是同时取方法/工具箱；时政条目如何标记。
- 给出一个 20–30 条的示例文件，覆盖全部卡片类型。

## Acceptance

回答中给出协议草案、示例、解析规则与合并语义；关键歧义由用户拍板。协议必须能由 Dart 确定性解析，不依赖第三方 Markdown 扩展。
