# 08 — 关键交互原型：遮罩揭晓、滑卡、配对

Type: prototype
Status: resolved
Blocked by: —

## Question

用最低成本做出可反应的交互原型，验证单手操作与“高频刺激”手感：

- 琥珀色遮罩：点击局部揭晓、长按全部揭晓、遮罩粒度（词/短语/整条结论）。
- 左右滑卡：判对/判错的手势阈值、回弹、撤销、与滚动冲突。
- 4×4 配对：点选反馈、错误抖动、完成态。
- 底部 TTS 控制条与拇指热区；深色/浅色切换。

原型可以是单页 Flutter 原型或可点击的静态稿；目标是让用户给出“手感对不对”的判断，不是交付产品。

## Acceptance

原型可运行/可点击；用户对遮罩粒度、滑卡阈值、配对反馈给出明确取舍；结论写入本文件 `## Answer`，原型路径链接在回答中。
